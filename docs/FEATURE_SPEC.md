# 기능 명세

## 1. 서비스 목표

사용자가 바둑 문제와 역사 문제를 별개의 학습으로 느끼지 않고 하나의 시대 미션으로 경험하도록 합니다. 무료 샘플에서 회원가입, 구독 또는 교재 구매, 기관 도입 상담으로 자연스럽게 이어지는 흐름을 제공합니다.

## 2. 사용자 역할

### 학생

- 시대 지도에서 학습 경로 확인
- 강의와 미션 수행
- 별, 배지, 유물 카드 수집
- 오답 다시 풀기
- 보호자 이메일 또는 휴대전화로 보호자 연결 초대 시작

### 학부모

- 학생이 보낸 초대를 수락하고 필요한 보호자·법정대리인 동의를 완료한 뒤 연결
- 연결이 `active`인 학생의 학습 시간과 정답률 확인
- 강점과 보완 영역 확인
- 구독과 교재 구매 관리

### 지도자

- 운영자 승인 또는 기관 초대를 거친 인증 지도자 계정 사용
- 반과 학생 관리
- 수업 패키지 열람 및 다운로드
- 과제 배포와 결과 확인
- 담당 반 학생만 조회

### 기관 관리자

- 기관 지도자 멤버십과 담당 반 관리
- 기관 라이선스와 좌석 관리
- 일반 지도자에게 기관 결제·환불 권한을 부여하지 않음

### 운영자

- 강의, 문제, 해설, 보상, 자료 관리
- 회원, 기관, 주문, 상담 관리
- 공지와 커뮤니티 운영

### 관리자

- 운영자 계정과 전체 권한 관리
- 강의 콘텐츠, 구독 플랜 및 계정 구독 권한 관리
- 결제·환불·감사 기록 조회

## 4. MVP 화면 목록

### 4.1 메인

목적은 서비스 개념을 이해시키고 첫 미션으로 진입시키는 것입니다.

완료 조건:

- 로그인하지 않은 사용자도 샘플 강의를 시작할 수 있음
- 핵심 메뉴가 데스크톱과 모바일에서 접근 가능함
- 교재, 상담, 로그인 전환점이 명확함

### 4.2 시대 여행

시대별 강의 진행 상태를 지도 또는 카드로 제공합니다.

필수 정보:

- 시대명과 순서
- 완료 강의 수와 전체 강의 수
- 잠금 및 개방 상태
- 현재 추천 강의
- 완료 보상

### 4.3 강의 플레이어

한 강의는 다음 단계로 구성합니다.

1. 역사 이야기: 2~3분 영상 또는 카드뉴스
2. 오늘의 한 수: 바둑 개념 1개
3. 판 위의 미션: 바둑 문제 3문항
4. 역사 미션: OX, 객관식, 드래그 문제 3문항
5. 생각 한 수: 역사와 바둑의 공통 사고 연결
6. 보상: 별, 배지, 유물 카드

완료 조건:

- 각 단계 완료 상태가 저장됨
- 답안 제출 후 결과와 해설이 표시됨
- 네트워크 오류가 발생해도 작성 중인 답안이 가능한 범위에서 유지됨
- 강의 완료 후 다음 강의가 추천됨

강의 접근 조건:

- 학생·학부모·지도자는 계정 구독 결제 후 수강 가능
- 구독 기간에는 `published` 상태의 모든 영상을 강의별 추가 결제 없이 재생 가능
- `published`이면서 무료 샘플로 지정된 영상은 비회원·비구독자도 재생 가능
- 무료 샘플이 아닌 공개 영상은 유효한 계정 구독이 있어야 재생 가능
- 구독은 결제 승인 시점에 시작하고 마지막 이용일의 다음 날 `00:00:00`에 종료
- 권한 판정은 `startsAt <= now < endsAt`으로 처리
- 구독이 종료되면 재생을 차단하고 새 구독을 안내
- 종료된 구독도 내 구독 내역에서 삭제하지 않음
- 관리자·운영자는 콘텐츠 검수를 위해 모든 강의를 미리보기 가능

### 4.3.1 강의 콘텐츠 CMS

관리자와 운영자만 다음 정보를 등록·수정할 수 있습니다.

- 강의 영상, 썸네일, 첨부 학습자료
- 과정, 시대, 강사, 재생 시간과 정렬 순서
- 무료 공개 여부: `무료 샘플` 또는 `구독 회원 전용`
- 임시저장, 공개, 보관 상태

초기 기본 콘텐츠는 `PRE-01` 선사시대 1강만 제공합니다. 선사시대 2강 이후와 고조선·삼국시대 등 나머지 강의는 코드에 고정하지 않고 관리자·운영자가 강의 CMS의 `새 강의 등록`과 수정 화면에서 업로드·편집·공개합니다.

강의 CMS에는 개별 가격·판매기간·시청 일수를 입력하지 않습니다. 구독 기간과 금액은 1개월 10,000원, 3개월 30,000원, 6개월 50,000원, 12개월 100,000원의 계정 구독 플랜으로 관리합니다. 공개된 신규 강의는 모든 유효 구독 계정에 자동으로 제공됩니다.

### 4.3.2 사용자 착수형 바둑미션

`판 위의 미션`은 정답 버튼을 고르는 퀴즈가 아니라 사용자가 9·13·19줄 바둑판 교차점에 직접 돌을 놓는 게임으로 구성합니다.

- 입문·기초·기본 18권, 144강과 문제은행 연결
- 강의당 개념 확인 3문제, 반복 훈련 5문제, 도전 2문제 권장
- 문제 목록에서는 제목, 난이도, 판 크기, 초기 판 썸네일, 풀이 상태를 카드로 표시
- 카드 클릭 시 PC는 중앙 확대 모달, 모바일은 전체화면 문제풀이 창 실행
- 같은 문제풀이 컴포넌트를 카드, 확대창, 전체화면, 지도자 수업 화면에서 재사용
- 사용자가 둔 합법 후보를 미확정 상태로 표시하고 `정답 확인`으로 서버에 제출
- 서버가 바둑 규칙과 정답 수순 트리를 판정한 뒤 상대 응수를 반환
- 따냄, 자충 금지, 패, 차례, 이미 놓인 자리 검사
- 서버가 직전 확정 판의 해시와 새 판의 해시를 비교해 반복 판을 최종 판정
- 패 규칙을 위반하거나 등록된 수순대로 진행하지 않은 착수는 사용자 화면에서 실패로 처리
- 한 수 문제와 여러 수의 연속 수순, 복수 정답, 허용 변화도, 금지 수순 제공
- 정답·허용·오답·금지·불법 착수별 피드백 제공
- 좌표 표시, 확대·축소, 현재 미확정 착수 되돌리기, 힌트, 재도전 제공
- 매 확정 착수마다 판 상태와 수순을 저장하여 이어하기 지원
- 정답 여부, 시도 횟수, 풀이시간, 힌트 사용, 점수를 학습기록과 오답노트에 저장
- 목표 달성 시 강의 진도와 보상을 서버에서 한 번만 확정
- 일반 미션은 계정 구독이 필요하며 공개 무료 샘플 미션은 비구독자도 체험 가능

MVP의 상대 응수는 운영자가 등록한 수순 트리를 사용하며 9·13·19줄 렌더링은 모두 1차 범위입니다. 범용 AI 자유대국은 후속 별도 범위입니다. 상세 명세는 [사용자 착수형 바둑문제·바둑미션 게임 기획](./BADUK_MISSION_GAME.md)을 참고합니다.

필수 항목:

- 관리자·운영자가 하나의 게시물에 수업 패키지 전체 등록
- 수업용 5분 영상, 빔프로젝터용 PPT, 인쇄 활동지 PDF
- 역사 퀴즈, 사용자 착수형 바둑미션 연결, 인쇄용 문제풀이 미션, 정답·해설, 수업 진행·가이드
- 도입 2분 → 개념 설명 5분 → 문제풀이 10분 → 역사 퀴즈 5분 → 마무리 3분의 25~30분 수업 흐름
- 기관과 반 목록
- 학생 초대 또는 코드 등록
- 반별 진도 설정
- 과제 생성, 마감일 설정, 배포

## 5. 핵심 상태 정의

### 강의 상태

- `locked`: 선행 조건을 충족하지 않음
- `available`: 시작 가능
- `in_progress`: 일부 단계 완료
- `completed`: 완료 조건 충족
- `review`: 복습 대상으로 지정

### 문제 풀이 상태

- `unanswered`: 답안 미제출
- `correct`: 정답
- `incorrect`: 오답
- `revealed`: 해설 확인

### 바둑미션 게임 상태

- `closed`: 문제 카드만 표시되고 확대창 닫힘
- `loading`: 문제와 기존 시도 로딩
- `ready`: 초기 판과 지시문 표시 완료
- `briefing`: 역사 상황과 목표 안내
- `player_turn`: 사용자 착수 가능
- `pending_move`: 정답 확인 전 미확정 착수 있음
- `validating_move`: 서버 착수 판정 중
- `opponent_turn`: 상대 자동 응수 중
- `retry`: 오답 피드백 후 재도전 대기
- `paused`: 이탈 또는 네트워크 중단
- `success`: 목표 달성
- `failed`: 제한 횟수 소진

### 보상 지급 원칙

- 동일 강의 완료 보상은 한 번만 지급
- 재도전으로 정답률은 개선할 수 있으나 보상 중복 지급 금지
- 보상 지급과 진도 완료는 하나의 서버 트랜잭션으로 처리

## 6. MVP 범위와 제외 항목

### MVP 포함

- 초기 기본 콘텐츠로 선사시대 1강만 제공
- 선사시대 2강 이후 모든 강의는 관리자·운영자가 CMS에서 추가·수정·공개
- 회원가입과 역할별 계정
- 강의·퀴즈·진도 저장
- 9·13·19줄 사용자 착수형 바둑미션, 카드형 목록, 확대 문제풀이 창과 상대 자동 응수
- 교재 QR 딥링크
- 별, 배지, 유물 카드
- 학생 대시보드
- 기본 지도자 반 관리
- 관리자 콘텐츠 등록

장기 교육과정은 18권·144강과 문제은행 확장을 유지하되 1차 배포 패키지에 콘텐츠를 미리 고정하지 않습니다.

### 초기 제외 권장

- 실시간 대국
- 공개 사용자 랭킹
- AI 자동 문제 생성
- 네이티브 모바일 앱
- 박물관 위치 기반 체험
- 복잡한 커뮤니티 사용자 작성 기능

## 7. 분석 이벤트

개인정보를 포함하지 않는 익명 이벤트 식별자를 사용합니다.

| 이벤트 | 주요 속성 |
|---|---|
| `hero_trial_clicked` | 유입 위치, 로그인 여부 |
| `trial_role_selected` | 학생/학부모/지도자 |
| `lesson_started` | 시대, 강의 ID, 진입 경로 |
| `question_answered` | 역사 문항 유형, 정답 여부, 시도 횟수 |
| `mission_started` | 미션 ID, 유형, 판 크기, 진입 경로 |
| `mission_player_opened` | 미션 ID, 모달·전체화면·수업 화면 표시 모드 |
| `mission_move_played` | 수번호, 결과 유형, 응답 시간 |
| `mission_hint_used` | 미션 ID, 힌트 단계 |
| `mission_zoom_changed` | 판 크기, 표시 모드, 배율 구간 |
| `mission_completed` | 소요 시간, 착수 수, 오답 수, 힌트 단계 |
| `lesson_completed` | 소요 시간, 정답률, 보상 |
| `qr_opened` | 교재 코드 유형, 로그인 여부 |
| `product_added` | 상품 ID, 수량 |
| `consultation_submitted` | 기관 유형, 예상 인원 구간 |
