# 계정 구독형 강의 CMS·시청 권한 설계

## 1. 확정 정책

- 강의별 판매·결제·이용기간은 사용하지 않습니다.
- 학생, 학부모, 지도자는 계정 단위 구독을 결제합니다.
- 구독 중에는 `published` 상태의 모든 강의영상을 별도 결제 없이 시청할 수 있습니다.
- 강의 글쓰기/CMS에서 `isFreeSample`을 설정한 공개 영상은 비회원과 비구독자도 무료로 시청할 수 있습니다.
- 무료 샘플 설정은 `published` 상태에서만 효력이 있으며 임시저장·보관 영상은 공개하지 않습니다.
- 관리자와 운영자는 콘텐츠 점검을 위해 모든 강의를 미리보기 할 수 있습니다.
- 구독은 토스페이먼츠 결제가 승인된 시각부터 시작합니다.
- 고정기간 선결제 상품이며 자동 갱신은 사용하지 않습니다.
- 유효한 구독이 있는 동안에는 중복 구독 결제를 차단합니다.
- 구독이 끝나면 영상 재생 권한이 사라지고 새 구독을 결제해야 합니다.
- 종료된 구독도 내 구독 내역에 남기며 결제일과 종료시각을 표시합니다.

## 2. 구독 플랜

| 플랜 | 기간 | 결제금액 | 영상 권한 |
|---|---:|---:|---|
| 1개월 구독 | 1개월 | 10,000원 | 구독 기간 중 모든 공개 영상 |
| 3개월 구독 | 3개월 | 30,000원 | 구독 기간 중 모든 공개 영상 |
| 6개월 구독 | 6개월 | 50,000원 | 구독 기간 중 모든 공개 영상 |
| 12개월 구독 | 12개월 | 100,000원 | 구독 기간 중 모든 공개 영상 |

운영 서버의 `SubscriptionPlan`이 화면과 주문의 기준 데이터입니다. 브라우저가 보낸 금액은 신뢰하지 않으며, 주문 서버가 활성 플랜의 최신 금액을 다시 조회해 주문금액을 확정합니다.

## 3. 시작·종료시각 계산

서비스 기준 시간대는 `Asia/Seoul`입니다.

1. `startsAt`과 `paidAt`은 토스 결제 승인 시각입니다.
2. 승인일에 플랜 개월 수를 달력 기준으로 더한 날짜가 마지막 이용일입니다.
3. `endsAt`은 마지막 이용일의 다음 날 `00:00:00`입니다.
4. 권한 판정은 `startsAt <= now < endsAt`으로 합니다.
5. 목표 월에 같은 일자가 없으면 그 달의 말일을 마지막 이용일로 사용합니다.

예시:

| 결제 승인일 | 플랜 | 마지막 이용일 | `endsAt`(한국시간) |
|---|---:|---|---|
| 2026-08-19 | 1개월 | 2026-09-19 | 2026-09-20 00:00:00 |
| 2026-08-19 | 3개월 | 2026-11-19 | 2026-11-20 00:00:00 |
| 2026-08-19 | 6개월 | 2027-02-19 | 2027-02-20 00:00:00 |
| 2026-08-19 | 12개월 | 2027-08-19 | 2027-08-20 00:00:00 |
| 2027-01-31 | 1개월 | 2027-02-28 | 2027-03-01 00:00:00 |

DB에는 UTC로 저장하고 화면에서 한국시간으로 변환합니다. 종료시각 계산은 반드시 결제 승인 서버에서 수행하며 브라우저 계산값은 안내용으로만 사용합니다.

## 5. 강의 CMS 입력 구조

관리자와 운영자가 다음 항목을 입력합니다.

| 분류 | 필드 |
|---|---|
| 기본정보 | `title`, `summary`, `instructor`, `difficulty` |
| 교육과정 | `level`, `course`, `era`, `order` |
| 미디어 | 원본 영상, 썸네일, `durationMinutes` |
| 학습자료 | PDF, PPT/PPTX, DOC/DOCX, HWP/HWPX |
| 공개관리 | `draft`, `published`, `archived`, `isFreeSample` |
| 감사정보 | `createdAt`, `updatedAt`, `updatedBy` |

강의 입력 화면에서 `무료 공개 여부`를 필수 선택값으로 제공합니다. `예`는 무료 샘플, `아니오`는 구독 회원 전용입니다. 강의별 `price`, `saleStartsAt`, `saleEndsAt`, `accessDays`는 사용하지 않으며 가격과 기간은 계정 구독 플랜에서만 관리합니다. 공개된 새 영상은 업로드 후 별도의 상품 등록 없이 모든 유효 구독 계정에 즉시 노출됩니다.

## 6. 결제·구독 발급 흐름

```text
사용자가 1·3·6·12개월 플랜 선택
  → 서버가 로그인·역할·기존 활성 구독 확인
  → 서버가 SubscriptionPlan의 최신 금액으로 주문 생성
  → 토스페이먼츠 결제
  → 성공 URL에서 서버가 paymentKey·orderId·amount 검증
  → 토스 승인 API 호출
  → 결제 승인시각을 startsAt/paidAt으로 저장
  → 한국시간 달력 규칙으로 endsAt 계산
  → 결제와 AccountSubscription을 한 트랜잭션으로 확정
  → 내 구독 내역 및 전체 강의 권한 활성화
```

새로고침·콜백 재시도에도 구독이 중복 생성되지 않도록 `paymentKey` 또는 `orderId`에 유니크 제약과 멱등 처리를 적용합니다.

## 7. 권장 데이터 모델

```text
SubscriptionPlan
├─ id
├─ label
├─ months
├─ price
├─ active
└─ updatedAt

AccountSubscription
├─ id, userId, planId, orderId, paymentId
├─ planLabelSnapshot
├─ monthsSnapshot
├─ amountSnapshot
├─ paidAt
├─ startsAt
├─ endsAt
├─ paymentStatus
└─ createdAt

Lesson
├─ id, title, summary, instructor
├─ level, course, era, order, difficulty
├─ durationMinutes, videoAssetId, thumbnailAssetId
├─ isFreeSample
├─ status
└─ createdAt, updatedAt, updatedBy
```

플랜명·개월 수·금액 스냅샷은 과거 결제내역 보존용입니다. 이후 플랜 정보가 바뀌어도 이미 결제된 구독의 금액과 종료시각은 바꾸지 않습니다.

## 8. 재생 보안

- `/lessons/{lessonId}/playback`에서 공개 상태를 먼저 검사한 뒤 `isFreeSample = true`이거나 활성 구독이 있는 경우에만 재생 URL을 발급합니다.
- 무료 샘플은 비로그인 요청도 허용하지만 원본 영상 주소를 직접 공개하지 않고 짧은 만료시간의 서명 URL을 사용합니다.
- 원본 영상 URL은 HTML이나 API 응답에 영구 주소로 노출하지 않습니다.
- 통과한 요청에만 짧은 만료시간의 서명 URL 또는 HLS 토큰을 발급합니다.
- `endsAt` 도달 후에는 열려 있던 페이지에서도 다음 재생 요청·세그먼트 갱신이 거절되어야 합니다.
- 관리자·운영자 미리보기 요청도 감사 로그에 남깁니다.

## 9. 화면 반영 사항

- 강의 페이지 상단: 네 가지 구독 플랜과 현재 구독 상태
- 강의 카드: `무료 샘플` 또는 `구독 회원 전체 공개` 표시
- 플레이어: 계정 구독 종료시각 표시
- 내 구독 내역: 플랜, 결제금액, 결제시각, 종료시각, 이용 중/종료 상태
- CMS: 콘텐츠 입력과 공개 상태만 제공
- 결제 결과: 구독 종료시각과 구독 내역 이동 버튼 제공
