# 계정 구독형 강의 CMS·시청 권한 설계

## 1. 확정 정책

현재 저장소에는 고정 구독 플랜, 서버 가격 기준 주문, 토스 결제 승인·조회·웹훅 검증, 멱등 계정 구독 발급과 내역, 운영자 전액 환불·권한 회수·기간별 관리자 대사와 CSV, 무료 샘플·활성 구독·운영자 재생 접근 판정, S3 호환 비공개 저장소의 MP4 단기 서명과 권한 기반 HLS 전달, 운영자 MP4 업로드·비동기 ClamAV 검사, 강의 CMS 등록·수정·공개·비공개·보관, 썸네일·PDF·PPT/PPTX·DOC/DOCX·HWP/HWPX 격리 및 ClamAV 검사, 공개 썸네일과 권한 기반 자료 다운로드, React 영상 플레이어와 6단계 강의 진도 저장이 구현되어 있습니다.

- 초기 기본 강의는 무료 샘플인 선사시대 1강 `PRE-01` 한 건만 제공합니다.
- 선사시대 2강 이후와 다른 시대 강의는 코드·배포 파일에 미리 넣지 않고 관리자·운영자가 CMS에서 업로드·편집·공개합니다.
- 강의별 판매·결제·이용기간은 사용하지 않습니다.
- 학생, 학부모, 지도자는 계정 단위 구독을 결제합니다.
- 구독 중에는 `published` 상태의 모든 강의영상을 별도 결제 없이 시청할 수 있습니다.
- 강의 글쓰기/CMS에서 `isFreeSample`을 설정한 공개 영상은 비회원과 비구독자도 무료로 시청할 수 있습니다.
- 무료 샘플 설정은 `published` 상태에서만 효력이 있으며 임시저장·보관 영상은 공개하지 않습니다.
- 관리자와 운영자는 콘텐츠 점검을 위해 모든 강의를 미리보기 할 수 있습니다.
- 구독은 토스페이먼츠 결제가 승인된 시각부터 시작합니다.
- 고정기간 선결제 상품이며 자동 갱신은 사용하지 않습니다.
- 유효한 구독이 있는 동안에는 중복 구독 결제를 차단합니다.
- 구독이 끝나면 영상 재생 권한이 사라지고 새 구독을 결제해야 합니다.
- 종료된 구독도 내 구독 내역에 남기며 결제일과 종료시각을 표시합니다.

## 2. 구독 플랜

| 플랜 | 기간 | 결제금액 | 영상 권한 |
|---|---:|---:|---|
| 1개월 구독 | 1개월 | 10,000원 | 구독 기간 중 모든 공개 영상 |
| 3개월 구독 | 3개월 | 30,000원 | 구독 기간 중 모든 공개 영상 |
| 6개월 구독 | 6개월 | 50,000원 | 구독 기간 중 모든 공개 영상 |
| 12개월 구독 | 12개월 | 100,000원 | 구독 기간 중 모든 공개 영상 |

운영 서버의 `SubscriptionPlan`이 화면과 주문의 기준 데이터입니다. 브라우저가 보낸 금액은 신뢰하지 않으며, 주문 서버가 활성 플랜의 최신 금액을 다시 조회해 주문금액을 확정합니다.

## 3. 시작·종료시각 계산

서비스 기준 시간대는 `Asia/Seoul`입니다.

1. `startsAt`과 `paidAt`은 토스 결제 승인 시각입니다.
2. 승인일에 플랜 개월 수를 달력 기준으로 더한 날짜가 마지막 이용일입니다.
3. `endsAt`은 마지막 이용일의 다음 날 `00:00:00`입니다.
4. 권한 판정은 `startsAt <= now < endsAt`으로 합니다.
5. 목표 월에 같은 일자가 없으면 그 달의 말일을 마지막 이용일로 사용합니다.

예시:

| 결제 승인일 | 플랜 | 마지막 이용일 | `endsAt`(한국시간) |
|---|---:|---|---|
| 2026-08-19 | 1개월 | 2026-09-19 | 2026-09-20 00:00:00 |
| 2026-08-19 | 3개월 | 2026-11-19 | 2026-11-20 00:00:00 |
| 2026-08-19 | 6개월 | 2027-02-19 | 2027-02-20 00:00:00 |
| 2026-08-19 | 12개월 | 2027-08-19 | 2027-08-20 00:00:00 |
| 2027-01-31 | 1개월 | 2027-02-28 | 2027-03-01 00:00:00 |

DB에는 UTC로 저장하고 화면에서 한국시간으로 변환합니다. 종료시각 계산은 반드시 결제 승인 서버에서 수행하며 브라우저 계산값은 안내용으로만 사용합니다.

## 5. 강의 CMS 입력 구조

관리자와 운영자가 다음 항목을 입력합니다.

| 분류 | 필드 |
|---|---|
| 기본정보 | `title`, `summary`, `instructor`, `difficulty` |
| 교육과정 | `level`, `course`, `era`, `order` |
| 미디어 | 원본 영상, 썸네일, `durationMinutes` |
| 학습자료 | PDF, PPT/PPTX, DOC/DOCX, HWP/HWPX |
| 공개관리 | `draft`, `published`, `archived`, `isFreeSample` |
| 감사정보 | `createdAt`, `updatedAt`, `updatedBy` |

강의 입력 화면에서 `무료 공개 여부`를 필수 선택값으로 제공합니다. `예`는 무료 샘플, `아니오`는 구독 회원 전용입니다. 강의별 `price`, `saleStartsAt`, `saleEndsAt`, `accessDays`는 사용하지 않으며 가격과 기간은 계정 구독 플랜에서만 관리합니다. 공개된 새 영상은 업로드 후 별도의 상품 등록 없이 모든 유효 구독 계정에 즉시 노출됩니다.

React `/admin/lessons`와 관리자 API는 기본정보·교육과정·영상·공개관리와 썸네일·PDF·PPT/PPTX·DOC/DOCX·HWP/HWPX 자료를 지원합니다. 신규 등록은 항상 `draft`이며 표준 6단계를 함께 생성합니다. 공개 전 영상과 6단계를 검사하고 삭제 대신 `archived`로 보관합니다. 학생 화면은 공개 썸네일과 접근 권한을 확인한 전체 지원 자료 다운로드를 제공합니다.

### 초기 데이터와 이후 업로드

| 구분 | 처리 방식 |
|---|---|
| 선사시대 1강 `PRE-01` | 초기 기본 데이터, `published`, 무료 샘플 |
| 선사시대 2강 이후 | CMS 신규 등록 |
| 고조선·삼국·고려·조선·근현대 | CMS 신규 등록 |
| 강의 수정 | 영구 ID는 유지하고 내용·정렬·공개 상태 수정 |

목록과 시대지도는 고정된 강의 수를 사용하지 않고 `published` 강의를 API에서 집계합니다. 강의가 없는 시대는 `준비 중`으로 표시하며 임시 데모 강의를 자동 생성하지 않습니다.

## 6. 결제·구독 발급 흐름

```text
사용자가 1·3·6·12개월 플랜 선택
  → 서버가 로그인·역할·기존 활성 구독 확인
  → 서버가 SubscriptionPlan의 최신 금액으로 주문 생성
  → 토스페이먼츠 결제
  → 콜백 또는 모바일 성공 URL에서 paymentKey·orderId·amount 전달
  → 서버가 토스 결제를 승인하고 주문번호·금액·paid 상태 검증
  → 결제 승인시각을 startsAt/paidAt으로 저장
  → 한국시간 달력 규칙으로 endsAt 계산
  → 결제와 AccountSubscription을 한 트랜잭션으로 확정
  → 내 구독 내역 및 전체 강의 권한 활성화
```

새로고침·콜백 재시도에도 구독이 중복 생성되지 않도록 `paymentKey`와 `orderId`에 유니크 제약과 멱등 처리를 적용합니다.

웹훅은 토스 `PAYMENT_STATUS_CHANGED` 이벤트를 수신하지만 본문 상태를 그대로 저장하지 않습니다. `paymentKey`로 토스 결제를 다시 조회해 주문번호와 금액을 검증한 뒤 성공·실패·환불을 반영합니다. 부분 환불은 누적 금액만 기록하고, 전액 환불이 확인될 때 구독을 `REFUNDED`로 변경하여 재생 권한을 회수합니다. 직접 환불 요청은 운영자·관리자 전용입니다.

## 7. 권장 데이터 모델

```text
SubscriptionPlan
├─ id
├─ label
├─ months
├─ price
├─ active
└─ updatedAt

AccountSubscription
├─ id, userId, planId, orderId, paymentId
├─ planLabelSnapshot
├─ monthsSnapshot
├─ amountSnapshot
├─ paidAt
├─ startsAt
├─ endsAt
├─ paymentStatus
└─ createdAt

Lesson
├─ id, title, summary, instructor
├─ level, course, era, order, difficulty
├─ durationMinutes, videoAssetId, thumbnailAssetId

├─ status

```

플랜명·개월 수·금액 스냅샷은 과거 결제내역 보존용입니다. 이후 플랜 정보가 바뀌어도 이미 결제된 구독의 금액과 종료시각은 바꾸지 않습니다.

## 8. 재생 보안

- `/lessons/{lessonId}/playback`에서 공개 상태를 먼저 검사한 뒤 `isFreeSample = true`이거나 활성 구독이 있는 경우에만 재생 URL을 발급합니다.
- 무료 샘플은 비로그인 요청도 허용하지만 원본 영상 주소를 직접 공개하지 않고 짧은 만료시간의 서명 URL을 사용합니다.
- 원본 영상 URL은 HTML이나 API 응답에 영구 주소로 노출하지 않습니다.
- 통과한 요청에만 짧은 만료시간의 재생 URL을 발급합니다. MP4는 객체 URL을 직접 서명하고 HLS는 재생목록마다 권한을 재검사한 뒤 같은 패키지의 세그먼트를 개별 서명합니다.
- React 플레이어는 HLS.js를 우선 사용하고 지원되지 않을 때 브라우저 네이티브 HLS로 대체합니다. 치명적 네트워크·미디어 오류는 한 번 복구한 뒤 사용자에게 오류를 표시합니다.
- 운영자는 비공개 저장소에 준비된 `lesson-hls/{lessonId}/{version}/master.m3u8`를 CMS에서 직접 연결할 수 있고, 정상 MP4는 영속 큐 워커가 원본 이하 최대 360p·720p fMP4 HLS로 자동 변환합니다. CloudFront 설정 시 MP4·HLS 조각은 CDN 서명 URL로 전환되며 미설정 시 S3 직접 서명으로 폴백합니다. 실제 CDN 배포와 GPU·1080p 이상 변환은 후속 운영 연동입니다.
- 서명 URL 기본 만료시간은 300초이며 설정 가능한 상한은 900초입니다. API 응답은 비공개·미저장 캐시 정책을 사용합니다.
- 서명 URL 자체에는 객체 경로가 포함될 수 있으므로 원본 버킷은 공개 접근을 차단하고 애플리케이션은 저장소 키를 별도 필드로 반환하지 않습니다.
- `endsAt` 도달 후에는 열려 있던 페이지에서도 다음 재생 요청·세그먼트 갱신이 거절되어야 합니다.
- 관리자·운영자 미리보기 요청도 감사 로그에 남깁니다.

## 8.1 영상 업로드 검증

- 운영자·관리자만 강의별 업로드 정책을 발급할 수 있습니다.
- 정책은 MP4 MIME, 요청한 파일 크기, 최대 2GB, 강의 ID 메타데이터를 제한하며 기본 300초 후 만료됩니다.
- 완료 API는 저장소의 MIME·실제 크기·강의 메타데이터와 첫 12바이트의 `ftyp` 시그니처를 다시 검사하고 `LessonVideoAsset`을 `quarantined`로 등록합니다.
- 별도 `video-scan-worker` 프로세스가 S3 `GetObject` 스트림을 ClamAV `INSTREAM`으로 전달합니다. 전체 영상을 API 메모리에 적재하지 않습니다.
- `ready` 검사 결과만 `Lesson.videoAssetKey`에 연결하며, 검사 중에는 기존 연결 영상을 유지합니다. 악성코드 탐지는 `rejected`, 스캐너·저장소 장애는 `error`로 기록합니다.
- 오류 작업은 1분·5분·30분 간격으로 최대 3회 자동 재시도하며 운영자가 CMS에서 재시도 횟수를 초기화할 수 있습니다. 2시간을 넘긴 `scanning` 잠금은 다른 워커가 회수할 수 있습니다.
- 업로드 요청·검사 대기·통과·탐지·오류·수동 재시도와 실제 연결 여부를 감사로그에 남깁니다.
- 별도 `video-cleanup-worker`는 기본 24시간 동안 완료되지 않은 업로드를 `purged`로 원자적으로 전환한 뒤 DB 삭제 큐에서 객체를 정리합니다.
- 정상 영상으로 교체된 이전 `lesson-videos/*.mp4` 객체도 기본 24시간 보존 후 정리합니다. 삭제 직전에 모든 강의의 `videoAssetKey`를 다시 조회하며 현재 참조된 객체이면 작업을 취소합니다.
- 삭제 장애는 1분·5분·30분·2시간·12시간 간격으로 최대 5회 재시도하고 예약·완료·참조 취소·실패를 감사로그에 남깁니다.
- 썸네일과 학습자료는 `quarantined`로 시작하며 파일 시그니처와 ClamAV 검사를 모두 통과한 경우에만 `ready`로 활성화합니다.
- 악성코드 탐지 파일은 `rejected`, 검사 서비스 장애 파일은 `quarantined` 또는 `error`로 유지합니다. 운영자는 검사 결과와 공급자, 시도 횟수와 현재 영상 여부를 CMS에서 확인합니다.

## 9. 화면 반영 사항

- 강의 페이지 상단: 네 가지 구독 플랜과 현재 구독 상태
- 강의 카드: `무료 샘플` 또는 `구독 회원 전체 공개` 표시
- 플레이어: 계정 구독 종료시각 표시
- 내 구독 내역: 플랜, 결제금액, 결제시각, 종료시각, 이용 중/종료 상태
- CMS: 콘텐츠 입력과 공개 상태만 제공
- 결제 결과: 구독 종료시각과 구독 내역 이동 버튼 제공
