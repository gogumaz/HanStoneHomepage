# 서비스 운영 정책

기준일: 2026-08-21

이 문서는 바둑타고 한국사 여행의 콘텐츠, 학습기록, 게시판, 개인정보,
알림 및 분석 운영 기준으로 채택한 권장안입니다. 사업자 표시값은 추후 입력하며,
법률 관련 문안은 출시 전 국내 변호사 또는 개인정보보호 책임자의 최종 검토를 거칩니다.

## 0. 상상바둑 운영 구조의 적용안

상상바둑 공식 사이트의 교육콘텐츠, 수업도우미, 교재, 용품, 고객센터 구조를
현재 서비스에 다음처럼 적용할 것을 제안합니다.

| 상상바둑 운영 구조 | 바둑타고 한국사 여행 적용안 |
|---|---|
| 상상바둑·애니바둑 | 시대별 한국사 이야기와 바둑미션 강의 |
| 바둑교육·집중교육·노래·동화·인성교육 | 지도자 수업도우미의 7종 수업자료 |
| 상상바둑 A~F 교재·해답 | 시대별 워크북·교사용 지도서·정답해설 |
| 강의보기·문제풀이·승급문제 | 강의 시청·필수 미션·추가 훈련 문제 |
| 공지·FAQ·1:1 문의 | 현재 설계된 고객센터 게시판 |
| 기간형 콘텐츠 구매 | 1·3·6·12개월 계정 구독 |

상상바둑의 콘텐츠 명칭과 자료를 실제로 이 서비스에서 사용할 때는 ㈜상상북스의
권리대장과 이용범위를 먼저 확인합니다.

## 1. 바둑미션 기본 운영 기준

### 점수

- 문제 기본점수는 100점입니다.
- 서버에 제출한 오답 1회당 20점을 감점합니다.
- 힌트는 단계별 사용 1회당 10점을 감점합니다.
- 허용 변화도에 포함된 수는 감점하지 않습니다.
- 제한시간이 있는 문제에서 시간이 끝나면 해당 시도는 실패, 점수는 0점입니다.
- 점수는 0점 미만으로 내려가지 않습니다.
- 모든 시도를 보존하며 대표 점수는 완료한 시도 중 최고점으로 표시합니다.
- 운영자는 문제별 기본점수·감점·제한시간을 덮어쓸 수 있습니다.

### 재도전과 체크포인트

- 기본 재도전 횟수는 무제한입니다.
- 평가·이벤트 문제만 운영자가 재도전 횟수를 제한할 수 있습니다.
- 단일 수 문제는 처음부터, 연속 수순 문제는 마지막 서버 확정 체크포인트부터 재도전합니다.
- 제한시간 종료는 실패로 기록하고, 재도전 가능 여부는 문제 설정을 따릅니다.
- 재도전해도 첫 시도 기록을 덮어쓰지 않습니다.

### 초기 콘텐츠

- 선사시대 1강은 총 6문항으로 시작합니다.
- 9줄 4문항, 13줄 1문항, 19줄 1문항으로 구성합니다.
- 필수 3문항과 추가 훈련 3문항을 구분합니다.
- 엔진과 CMS는 처음부터 9·13·19줄을 모두 지원합니다.

## 2. 분류·번호·통계

### 분류

`과정`, `문제군`, `난이도`를 별도 필드로 관리합니다.

- 과정: 교육과정 또는 시대·단원 구조
- 문제군: 활로, 따내기, 연결, 자충, 패 등 학습 목표
- 난이도: 입문, 초급, 중급, 고급

난이도 이름은 화면 표시값이며 정렬과 추천에는 별도의 숫자 레벨을 사용합니다.

### 문제번호

- 문제 ID는 UUID 또는 불투명 영구 ID로 발급하고 변경하지 않습니다.
- 화면의 문제번호와 정렬순서는 별도 필드로 관리합니다.
- 공개 후 재정렬해도 학습기록은 영구 ID에 연결되어 유지됩니다.
- 삭제 대신 `archived` 상태를 사용하고 기존 학습기록을 보존합니다.

### 정답률

- 첫 시도 정답률과 최종 완료율을 별도로 표시합니다.
- 재도전은 첫 시도 정답률의 분모·분자에 다시 포함하지 않습니다.
- 비회원 무료 샘플 기록은 회원 통계에서 제외하고 별도 체험 통계로 집계합니다.
- 운영자·QA 계정과 자동 테스트 데이터는 운영 통계에서 제외합니다.

## 3. 문제 추천

- 추천 기능은 핵심 학습·결제 기능 안정화 이후 3차 범위로 구현합니다.
- 회원의 유효한 문제 시도가 5회 미만이면 교육과정 순서와 운영자 추천을 사용합니다.
- 5회 이상이면 최근 30일의 오답 문제군, 난이도, 마지막 학습일을 기준으로 추천합니다.
- 완료하지 않은 선행 필수 문제를 가장 먼저 추천합니다.
- 개인정보나 보호자·기관 정보를 추천 점수에 사용하지 않습니다.
- 추천 이유를 `최근 오답 유형`, `복습 시점`, `다음 과정`처럼 사용자에게 설명합니다.

## 4. 영상 및 파일

### 영상

- 영상 원본은 공개 웹 경로가 아닌 비공개 객체 저장소에 보관합니다.
- 업로드·조회 권한은 관리자와 운영자에게만 부여하고 접근기록을 남깁니다.
- 원본 형식은 MP4 또는 MOV, 파일당 최대 2GB를 기본값으로 합니다.
- HLS 권한 전달은 재생목록 프록시와 세그먼트 단기 서명을 사용합니다. CDN은 CloudFront 신뢰 키 그룹의 SHA-256 서명 URL을 사용하고 미설정 환경은 S3 직접 서명으로 폴백합니다. 자동 다중 화질 변환 방식과 실제 배포·비용은 별도로 확정합니다.

### 일반 첨부파일

| 용도 | 허용 확장자 | 파일당 최대 크기 |
|---|---|---:|
| 이미지 | jpg, jpeg, png, webp | 10MB |
| 문서·활동지 | pdf | 30MB |
| 교사용 편집 자료 | pptx, docx, xlsx | 100MB |

- exe, js, html, bat, cmd, ps1, 매크로 포함 Office 파일과 암호화 압축파일은 차단합니다.
- 실제 MIME, 확장자, 파일 시그니처를 모두 검사합니다.
- 업로드 파일은 악성코드 검사 완료 후에만 공개합니다.
- 저장 파일명은 서버가 생성하고 원본 파일명은 메타데이터로만 보관합니다.

## 5. 게시판 신고·검토·재심

- 신고 사유는 개인정보 노출, 욕설·괴롭힘, 불법정보, 저작권, 광고·도배, 기타로 구분합니다.
- 신고 횟수만으로 게시물을 자동 삭제하지 않습니다.
- 개인정보 노출, 불법정보, 신체 위협은 운영자가 즉시 임시 숨김 처리할 수 있습니다.
- 일반 신고는 영업일 기준 2일 이내 1차 검토합니다.
- 지도자 게시물 반려 시 사유와 수정 요청을 기록합니다.
- 작성자는 결과 통지 후 7일 이내 한 번 재심을 요청할 수 있습니다.
- 재심은 최초 처리자와 다른 운영자가 영업일 기준 5일 이내 판단합니다.
- 모든 상태 변경은 담당자, 시각, 사유를 감사로그로 남깁니다.

## 6. 개인정보 및 기록 보존

- 회원정보는 회원 상태 유지 중 보관하고 탈퇴 완료 시 지체 없이 삭제하거나 익명화합니다.
- 법정 보존 대상은 일반 회원정보와 분리하고 목적 외로 사용하지 않습니다.
- 표시·광고 기록은 6개월 보관합니다.
- 계약·청약철회 기록은 5년 보관합니다.
- 결제 및 재화·서비스 공급 기록은 5년 보관합니다.
- 소비자 불만·분쟁처리 기록은 3년 보관합니다.
- 법정 보존기간이 끝나면 배치 작업으로 파기하고 파기 결과를 기록합니다.
- 운영 로그는 기본 90일, 보안사고 조사 대상으로 지정된 로그는 사건 종료 시까지 분리 보관합니다.
- 원시 분석 이벤트는 13개월, 개인을 식별할 수 없게 집계한 통계는 3년 보관합니다.
- 백업 속 탈퇴 데이터는 운영 조회에서 즉시 차단하고 백업 보존주기 안에서 순차 파기합니다.

전자상거래 기록 보존기간은 국가법령정보센터의 「전자상거래 등에서의
소비자보호에 관한 법률 시행령」 제6조를 기준으로 합니다.
개인정보가 불필요해지면 지체 없이 파기한다는 「개인정보 보호법」 제21조를 함께 적용합니다.

## 7. 알림

- 기본 알림은 앱 내 알림과 이메일입니다.
- SMS는 결제·환불, 계정 보안, 수업 취소, 중대한 장애처럼 즉시 확인이 필요한 경우에만 사용합니다.
- 광고성 알림은 채널별 사전 동의를 받은 사용자에게만 발송합니다.
- 사용자는 알림 종류와 채널별 수신 여부를 변경할 수 있습니다.
- 거래·보안 필수 알림은 마케팅 수신 거부와 분리합니다.
- 발송 요청 ID로 중복 발송을 방지하고 성공·실패 상태를 기록합니다.

## 8. 분석

- MVP는 자체 서버의 1차 이벤트 로그를 기준으로 합니다.
- 외부 분석 도구를 도입할 경우 개인정보 처리방침과 동의 범위를 먼저 갱신합니다.
- 이메일, 전화번호, 이름, 상담 내용, 결제수단 세부정보를 분석 이벤트에 넣지 않습니다.
- 사용자 식별이 필요하면 내부 난수 ID를 사용하고 원 계정정보와 분리합니다.
- 필수 이벤트는 가입 완료, 강의 시작·완료, 문제 시도·완료, 구독 시작·종료입니다.
- 관리자·QA·자동화 계정은 운영 지표에서 제외합니다.
