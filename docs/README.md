## 현재 구현 상태

- HTML, CSS, JavaScript로 제작된 반응형 프론트엔드 프로토타입 유지
- React + TypeScript, Vite, React Router, TanStack Query 전환 골격과 타입검사·단위테스트·멀티페이지 빌드 구성
- `/app.html`에서 React 전환 진입점 확인 가능
- `/account`에서 이메일 회원가입·로그인·로그아웃, 이메일 인증·비밀번호 재설정, 소셜 계정 연결·해제와 재인증 기반 계정 탈퇴 가능
- `/guardian`에서 학생의 보호자 초대와 보호자의 동의·연결·연결 해제 가능
- `/guardian`에서 활성 연결·동의 기반 학생 강의·단계 진도와 최근 학습 리포트 확인 가능
- `/lessons`에서 API 기반 시대 선택·공개 강의 목록·준비 중 상태·강의 상세 조회 가능
- `/dashboard`에서 실제 학생 진도 기반 전체·시대별 여행지도, 최근 학습과 접근 가능한 다음 강의 확인 가능
- 강의 상세에서 무료·구독·운영자 접근 판정, 운영자 MP4 직접 업로드·검사, CloudFront 또는 S3 MP4 단기 서명 및 권한 기반 HLS 재생과 로그인 사용자의 6단계 진도·최종 완료 저장 가능
- `/admin/lessons`에서 운영자·관리자 강의 등록·수정, 영상 연결과 공개·비공개·보관 가능
- 강의 썸네일·PDF·PPT/PPTX·DOC/DOCX·HWP/HWPX는 격리 후 파일 시그니처·컨테이너 구조와 ClamAV 검사를 통과한 경우에만 활성화하고, 공개 썸네일과 권한 기반 학습자료를 단기 서명 URL로 제공
- NestJS API, Prisma 초기 회원·권한 데이터 모델과 PostgreSQL 마이그레이션 구성
- Era·Lesson 카탈로그 모델과 6개 시대·무료 샘플 `PRE-01` 초기 데이터 구성
- 1·3·6·12개월 구독 플랜, 계정 구독 기간, 강의 단계·진도·멱등 완료 데이터 모델 구성
- HttpOnly 세션 쿠키, 세션 갱신·폐기, 공개 역할 제한, 역할 가드, 요청 ID와 공통 API 응답 구현
- Docker 로컬 환경, 운영 배포 템플릿, GitHub Actions CI와 Playwright 스모크 테스트 구성
- 시대 선택, 바둑 문제, 모달, 토스트 등 클라이언트 인터랙션 구현
- `/missions`에 9·13·19줄 문제 카드·초기 판 썸네일·모바일 터치 스크롤·확대 플레이어와 검색·상세 필터·즐겨찾기를 구현하고, 미확정 착수·서버 자동채점·상대 자동 응수·힌트·이어하기를 연결
- 강의 상세에서 `lessonId`로 공개 바둑미션을 조회하고 선택한 미션 풀이 창으로 바로 연결
- `/admin/missions`에 초기 돌·대표 정답·금지 수·수순 트리·힌트·해설을 저장하고 자동검수 후 게시하는 바둑문제 입력기를 구현
- 문제 입력기에서 학습기록을 남기지 않는 서버 판정 미리보기와 완료율·평균 점수·오답·힌트·풀이시간 통계를 제공
- 네이버·카카오톡·Google 간편 로그인, state·PKCE·nonce 검증, 소셜 계정 세션 발급과 로그인 계정의 안전한 연결·해제 구현
- 토스페이먼츠 주문·결제 승인·조회 검증·웹훅·멱등 구독 발급·운영자 전액 환불과 React 구독 내역 구현
- `/admin/payments`에서 주문·구독·환불 불일치 확인, 토스 원본 재동기화와 확인 절차가 포함된 전액 환불 가능
- `/admin/consultations`에서 기관 상담 검색·상세·업무 상태 관리 가능
- `/admin/inquiries`에서 회원 비공개 문의 검색·상세·안전 검사 첨부 다운로드·답변 등록·수정과 검토·종료 상태 관리 및 DB 아웃박스·재시도 워커 기반 답변 이메일 알림 가능
- `/notifications`에서 로그인 사용자의 문의 답변 앱 알림·미확인 수와 개별·전체 읽음 처리, 본인 문의 답변 딥링크 이동 가능
- 게시판 8종의 목록·상세·권한별 글쓰기와 개발용 임시 저장 구현
- 지도자 수업도우미의 25~30분 수업 흐름과 7개 자료 일괄 첨부 구현
- 계정 구독형 강의 CMS, 영상별 무료 샘플 설정, 1·3·6·12개월 플랜, 개발용 구독·종료와 수강 진도 구현
- OAuth 운영 앱 실연동과 운영 AWS 계정의 CloudFront 배포·OAC·키 그룹·도메인 연결은 추가 필요. 자동 HLS 변환 워커는 구현됐으며 운영 영상량에 맞춘 GPU·동시 처리 규모 확정이 남음
- 홈페이지 기준 기획서: `바둑타고_한국사여행_홈페이지_기획서_20260917.pptx`
- 바둑게임 기준 기획서: `바둑문제_입력기_유저용_기획서_플로차트_확대창기능추가.pptx`

## 문서 관리 원칙

기능 또는 API가 변경되면 코드와 같은 작업 단위에서 관련 문서를 함께 갱신합니다. 구현된 내용과 예정된 내용을 혼동하지 않도록 다음 표기를 사용합니다.

- **구현됨**: 현재 저장소에서 동작하는 기능
- **연동 필요**: UI는 있으나 서버 또는 외부 서비스 연결이 필요한 기능
- **예정**: 아직 UI와 로직이 모두 구현되지 않은 기능
