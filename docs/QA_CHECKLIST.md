# QA 체크리스트

릴리스 전 결과를 `통과`, `실패`, `해당 없음`으로 기록합니다. 실패 항목에는 재현 절차와 담당자를 남깁니다.

## 1. 기본 실행

- [ ] `node dev-server.mjs` 실행 시 오류가 없음
- [ ] `/`, `/styles.css`, `/script.js`, 주요 이미지가 HTTP 200으로 응답함
- [ ] 개발자 콘솔에 JavaScript 오류가 없음
- [ ] 새로고침과 직접 URL 진입이 정상 동작함
- [ ] 운영 배포에서 소스맵과 환경 설정이 의도대로 구성됨

## 2. 내비게이션

- [ ] 모든 상단 메뉴가 올바른 섹션으로 이동함
- [ ] 모바일 메뉴가 열리고 닫힘
- [ ] 메뉴를 선택하면 모바일 메뉴가 자동으로 닫힘
- [ ] 스크롤 후에도 고정 헤더가 콘텐츠를 과도하게 가리지 않음
- [ ] `본문 바로가기` 링크가 키보드 포커스에서 표시됨

## 3. 메인과 시대 여행

- [ ] 무료 체험 버튼이 체험 모달을 엶
- [ ] 샘플 강의 버튼이 미션 모달을 엶
- [ ] 시대 탭 선택 시 제목, 설명, 태그, 버튼 문구가 함께 변경됨
- [ ] 선택된 시대가 시각적 상태와 `aria-selected`로 표현됨
- [ ] 잠금 시대의 실제 서비스 동작이 정책과 일치함
- [ ] 모바일에서 시대 탭을 가로 스크롤할 수 있음

## 4. 현재 바둑 문제·역사 퀴즈 데모

- [ ] 바둑판 A/B/C 지점이 마우스와 키보드로 선택 가능함
- [ ] B 선택 시 정답 피드백이 표시됨
- [ ] A 또는 C 선택 시 재도전 안내가 표시됨
- [ ] 역사 퀴즈의 정답과 오답 피드백이 정확함
- [ ] 연속 클릭과 네트워크 재시도 시 답안이 중복 제출되지 않음
- [ ] 정답과 오답을 색상만으로 구분하지 않음
- [ ] 화면 읽기 도구가 결과 메시지를 읽을 수 있음

## 4.1 사용자 착수형 바둑미션 게임

- [ ] 같은 좌표 데이터 구조로 9·13·19줄 바둑판이 정확히 렌더링됨
- [ ] 과정·권·강·판 크기·유형·난이도·풀이 상태 필터가 문제 카드 목록에 적용됨
- [ ] 문제 카드에 제목, 난이도, 판 크기, 초기 판 썸네일, 풀이 상태가 표시됨
- [ ] 카드 클릭 시 PC는 중앙 확대 모달, 모바일은 전체화면 문제풀이 창이 열림
- [ ] 카드·모달·전체화면·지도자 수업 화면이 같은 문제와 시도 상태를 사용함
- [ ] 사용자가 바둑판 교차점에 마우스·터치·키보드로 직접 착수할 수 있음
- [ ] 착수 후보가 `pendingMove`로 보이고 `정답 확인` 전에는 서버 확정 수순에 포함되지 않음
- [ ] 현재 미확정 착수를 되돌린 뒤 다른 좌표를 선택할 수 있음
- [ ] 사용자의 차례가 아니거나 상대 응수 중에는 착수할 수 없음
- [ ] 판 밖, 이미 놓인 자리, 자충, 패, 차례 위반을 불법 착수로 판정함
- [ ] 상대 돌을 둘러싸면 돌이 정확히 제거되고 잡은 돌 수가 갱신됨
- [ ] 정답 수를 두면 상대 돌이 등록된 수순에 따라 자동 응수함
- [ ] 한 수와 여러 수의 연속 수순 미션을 끝까지 진행할 수 있음
- [ ] 복수 정답, 허용 변화도, 금지 수순이 단일 정답과 구분되어 판정됨
- [ ] 정답·허용·오답·금지·불법 착수에 서로 다른 피드백이 표시됨
- [ ] 오답 피드백 후 체크포인트 또는 처음부터 재도전할 수 있음
- [ ] 힌트 1·2·3단계와 사용 이력이 저장됨
- [ ] 문제별 배점·제한시간·힌트 감점 정책을 서버가 계산함
- [ ] 페이지 새로고침 후 마지막 서버 확정 수에서 이어짐
- [ ] 중복 탭·다른 기기에서 판 상태가 충돌하면 최신 판을 다시 불러옴
- [ ] 동일 `clientMoveId`가 중복 처리되지 않음
- [ ] 정답 여부, 시도 횟수, 풀이시간, 힌트, 점수가 학습기록에 저장됨
- [ ] 오답 문제는 오답노트에 남고 재정답 후에는 복습 완료 상태가 표시됨
- [ ] 무료 샘플 미션과 구독 전용 미션의 접근 권한이 구분됨
- [ ] 완료 보상은 서버 성공 판정 후 한 번만 지급됨
- [ ] 운영자 CMS가 9·13·19줄 초기 판, 착수 차례, 정답 수순, 변화도, 힌트, 해설을 저장함
- [ ] 판 크기 변경 시 범위를 벗어난 기존 돌을 임의 삭제하지 않고 변경을 차단함
- [ ] 운영자 CMS가 불법 수, 성공 경로 없음, 도달 불가 노드, 무한 반복을 공개 전에 차단함
- [ ] 확대·축소와 좌표 표시 전환 후에도 착수 위치, 돌, 교차점이 어긋나지 않음
- [ ] 19줄 모바일 확대 상태에서 스크롤·터치 착수가 충돌하지 않음
- [ ] 닫기, 뒤로가기, `Escape`, 모달 포커스 가두기와 실행 카드로의 포커스 복귀가 동작함

## 5. 모달과 폼

- [ ] 로그인, 체험, 미션, 상담 모달이 각각 열림
- [ ] 닫기 버튼, 배경 클릭, `Escape` 키로 닫힘
- [ ] 모달이 열리면 포커스가 모달 내부로 이동함
- [ ] `Tab`과 `Shift+Tab` 포커스가 모달 안에서 순환함
- [ ] 모달을 닫으면 실행 버튼으로 포커스가 돌아감
- [ ] 필수 입력값이 비어 있으면 제출되지 않음
- [ ] 연락처, 비밀번호, 문의 내용의 서버 검증이 적용됨
- [ ] 상담 제출 시 개인정보 동의 기록이 저장됨
- [ ] 서버 오류 시 입력한 내용이 사라지지 않음

## 7.1 계정 구독형 강의 CMS와 시청 권한

- [ ] 관리자와 운영자만 강의 등록·수정·공개·보관을 실행할 수 있음
- [ ] 일반 회원이 관리 API를 직접 호출하면 `403`을 반환함
- [ ] 강의 CMS에 개별 가격·판매기간·시청 일수 필드가 없음
- [ ] 강의 CMS에서 무료 공개 여부를 `예·아니오`로 필수 선택할 수 있음
- [ ] `published + isFreeSample=true` 영상은 비회원과 비구독자도 재생 가능함
- [ ] `draft` 또는 `archived` 영상은 무료 샘플이어도 일반 사용자에게 노출·재생되지 않음
- [ ] 무료 샘플이 아닌 공개 영상은 활성 구독 없이는 재생할 수 없음
- [ ] 1개월 10,000원, 3개월 30,000원, 6개월 50,000원, 12개월 100,000원이 표시됨
- [ ] 주문 서버가 `SubscriptionPlan`의 최신 금액을 재검증함
- [ ] 결제 승인 시각이 `paidAt`과 `startsAt`으로 저장됨
- [ ] 8월 19일 1개월 결제의 `endsAt`이 한국시간 9월 20일 00:00:00임
- [ ] 월말 일자가 없는 경우 목표 월 말일까지 이용 후 다음 날 00시에 종료됨
- [ ] 권한 판정이 `startsAt <= now < endsAt`과 일치함
- [ ] 유효 구독 중 모든 공개 영상을 강의별 추가 결제 없이 재생할 수 있음
- [ ] 종료시각 이후에는 모든 영상 재생이 즉시 차단됨
- [ ] 종료된 구독도 내 구독 내역에서 사라지지 않음
- [ ] 구독 내역에 플랜, 결제금액, 결제일, 종료시각, 이용 중·종료 상태가 표시됨
- [ ] 활성 구독 중 중복 구독 결제가 차단됨
- [ ] 과거 결제 플랜·개월 수·금액 스냅샷이 이후 플랜 변경의 영향을 받지 않음
- [ ] 원본 영상 URL을 권한 없이 직접 열 수 없음
- [ ] 업로드 영상·이미지·문서의 MIME, 시그니처, 크기, 악성 파일을 검사함
