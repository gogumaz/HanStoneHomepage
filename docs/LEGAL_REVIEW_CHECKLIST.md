# 미성년자·보호자 동의 정책 법무 검토 체크시트

이 문서는 법률 자문을 대신하지 않습니다. 국내 변호사 또는 개인정보보호 책임자가 아래 항목과 실제 서비스 화면을 검토하고 승인 증적을 남긴 뒤에만 운영 출시 승인을 완료합니다.

## 검토 대상

- `src/features/legal/PrivacyPage.tsx`의 개인정보 처리 목적·수집 항목·보유기간·철회 안내
- `src/features/auth/AuthPage.tsx`의 연령대 선언과 만 14세 미만 계정 제한 안내
- `src/features/guardian/GuardianPage.tsx`의 아동 계정 활성화, 학습정보 열람, 유료 구독 동의가 서로 분리된 구조
- `server/src/guardian/guardian.service.ts`의 동의 유형·버전·범위·확인방법·시각·철회 이력
- `server/src/subscription/subscription.service.ts`의 미성년자 유료 구독 동의 확인
- `docs/ACCOUNT_PERMISSION_POLICY.md`와 `docs/OPERATIONS_POLICY.md`의 권한·보유·철회·환불 정책

## 필수 판단 항목

- [ ] 만 14세 미만 아동의 법정대리인 동의 획득·확인 방법이 충분함
- [ ] 아동에게 표시하는 문안이 이해하기 쉬우며 수집 항목을 최소화함
- [ ] 아동 계정 활성화, 학습정보 열람, 유료 구독 동의를 별도로 받는 방식이 적절함
- [ ] 보호자 관계 확인 수준과 오인·도용 대응 절차가 적절함
- [ ] 동의 철회 시 계정·학습기록·결제·법정 보존정보의 처리 방식이 적절함
- [ ] 개인정보 처리 목적·항목·보유기간·파기·권리행사 창구가 실제 운영과 일치함
- [ ] 이용약관·개인정보처리방침·환불정책 사이에 충돌이 없음
- [ ] 출시 대상 플랫폼과 결제 방식에 필요한 추가 고지·동의가 없음

## 승인 기록

- 정책 버전 또는 후보 커밋 SHA:
- 검토자 이름·소속·자격:
- 검토 완료 일시(ISO 8601):
- 승인 결과: 승인 / 조건부 승인 / 반려
- 조건·수정 요청:
- 승인 문서 또는 전자결재 증적 위치:
- 개인정보보호 책임자 확인:

승인된 정책 버전, 검토 완료 일시, 검토자와 증적 위치를 변경승인 기록에 첨부합니다. 조건부 승인은 조건을 코드와 문안에 반영하고 재확인하기 전까지 완료로 간주하지 않습니다.

서명된 최종 승인 문서의 SHA-256을 계산해 운영 환경의 `LEGAL_POLICY_APPROVAL_SHA256`에 등록하고, 승인 시각은 `LEGAL_POLICY_APPROVED_AT`, 승인된 정책 버전은 `LEGAL_POLICY_VERSION=guardian-link-v1`로 등록합니다. 세 값 중 하나라도 없거나 정책 버전이 현재 코드와 다르면 운영 앱과 프리플라이트가 시작되지 않습니다. 해시만 운영 설정에 저장하며 승인 문서 원본과 검토자 정보는 접근 통제된 변경승인 시스템에 보관합니다. 프리플라이트 후 `verify:legal-approval-binding`을 실행해 승인 증빙·운영 환경·프리플라이트의 원본 SHA-256과 후보 일치 결과도 같은 변경승인 기록에 보관합니다.
