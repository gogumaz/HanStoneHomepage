# Q&A 착수 인터뷰

요청을 바로 실행하지 말고 Q&A로 검증한다. 목표, 산출물·성공 기준, 범위·제외 범위, 입력·맥락, 제약·의존성, 검증·예외의 여섯 축을 각 배점에 따라 평가한다.

매 응답 뒤에 다음을 갱신한다.

1. 확정된 사실과 명시적 가정
2. 현재 이해도 점수와 점수 근거
3. 남은 열린 질문과 치명도
4. 다음 질문(최대 세 개)과 질문 이유

90점 이상이면서 치명적 열린 질문이 없을 때만 `_workspace/00_qa_intake.md`를 작성하고 사용자에게 승인받는다. 사용자가 "알아서 결정해"라고 하면 선택지를 제시하고, 선택된 가정을 승인 가능한 항목으로 기록한다. 승인 전에는 계획·실행으로 넘어가지 않는다.
