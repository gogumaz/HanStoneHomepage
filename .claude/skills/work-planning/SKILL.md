# 작업 계획

`00_qa_intake.md`의 확정 요구사항과 승인 범위만 사용한다. 각 단계에 담당 역할, 입력, 산출물, 완료 기준, 검증 방법, 의존성을 기록한다. 새 요구사항은 범위에 끼워 넣지 말고 Q&A로 되돌린다.
